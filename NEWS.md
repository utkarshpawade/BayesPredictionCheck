# predictCheckR 0.1.0

* Initial release.
* Core functions: `simulate_ppc()`, `ppc_diagnostics()`, `plot_ppc_overlay()`,
  `plot_ppc_stat()`, `compare_models_ppc()`.
* Custom ggplot2 theme: `theme_ppc()`.
* Supports Gaussian and Binomial likelihood families.
* Bundled example dataset (`example_data`).
* Vignette: "Posterior Predictive Checking with predictCheckR".
